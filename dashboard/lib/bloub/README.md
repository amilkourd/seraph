# lib/bloub

The Bloub engine by Jérémy Perret (MIT, `LICENSE`): `src/bot/*.ts` of github.com/jeremy-prt/bloub at the commit in
`.source-sha`, tests left out. One change: `engine.ts` has a `blinks` switch (marked « Seraph »), off for our flame,
whose eyes stay wide open. Our only file is `flamme.ts` (the flame body and the module colours);
`components/Flamme.tsx` renders a frame the way Bloub's `BloubBot.vue` does.
